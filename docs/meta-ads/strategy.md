# 메타 광고 전략

> **목적:** 검색하지 않는 배우자를 메타 광고로 데려올 수 있는지, 얼마에 데려오는지 확인하는 광고의 설계와 소재를 정한다.
>
> **결론:** 캠페인 1개·소재 5개에 총 10만 원(10월 2~5일)을 쓰고 목표는 트래픽(랜딩 페이지 조회)이다. 메시지 승패는 보지 않고 병원 연결 1건당 비용을 핵심 숫자로 본다. 결과 표는 `make meta-report`로 갱신한다.

[솔루션 0단계 "닿기"](../solution-direction.md#솔루션-방향)를 실제 숫자로 처음 확인하는 광고다. 검증 계획은 [validation](../validation.md#메타-광고-유입-검증)에 있다.

## 목적

> **검색하지 않는 배우자를 데려올 수 있나, 얼마에?**

- 서비스가 병원에 파는 것은 "판단을 마친 배우자"다([비즈니스 임팩트](../business-impact.md)). 배우자가 들어오지 않으면 체크·결과·병원 목록도, 병원 광고 수익도 성립하지 않는다.
- 솔루션 문서도 유입을 1순위 리스크로 둔다. 한국에서 배우자를 광고로 데려올 수 있는지 보여주는 공개 자료는 찾지 못했다.
- 광고 목표는 "랜딩 페이지 조회"로 둔다. 참여 목표로 돌리면 메타가 반응할 사람에게만 보여줘 클릭이 안 나온다.
- 어떤 메시지가 이기는지는 보지 않는다. 메타가 예산을 반응 좋은 소재에 몰아주므로 소재별 숫자는 참고만 한다.

## 설계

| 항목 | 값 |
|---|---|
| 구조 | 캠페인 1개, 광고 세트 1개, 소재 5개. 예산 분배는 메타에 맡긴다 |
| 목표 | 트래픽(랜딩 페이지 조회) |
| 타겟 | 국내 전체, 어드밴티지+ 타겟. 지금은 유입 성과를 보는 단계라 메타 최적화에 맡긴다. 이후 목표를 체크 완료·병원 연결 전환으로 바꾸면 메타가 전환하는 사람 쪽으로 타겟을 좁힌다([단계별 계획](#단계별-최적화-계획)). 연령·성별 분석으로 실제 유입을 나눠 본다 |
| 예산·기간 | 총 10만 원, 10월 2일 밤 ~ 10월 5일(월) 23:59. 5만 원이면 병원 연결이 한 자릿수라 숫자 하나에 결과가 흔들려 늘렸다 |
| 랜딩 | 배우자 체크 시작 화면 |
| 전제 | 서비스 배포, 이벤트 기록(체크 완료, 병원 링크 클릭·전화 걸기) 동작 |

**볼 숫자**

| 숫자 | 의미 |
|---|---|
| 클릭률, 클릭당 비용 | 배우자가 이 주제에 반응하나 |
| 체크 완료율 → 병원 연결률 | 들어온 배우자가 "판단을 마친 배우자"까지 가나 |
| 병원 연결 1건당 비용 | 병원 광고비로 이 유입 비용을 감당할 수 있나. 비즈니스 임팩트의 핵심 숫자 |
| (2차) 경로별 퍼널 | 체크 시작 → 체크 완료 → 병원 연결을 당사자·배우자로 나눠 본다. H1 판정 |
| (2차) 판정 단계별 병원 연결률 | 검사 권유 단계가 병원 연결로 이어지나(H2, 북극성 지표). 사람 수 기준 |

**한계**
- 광고는 3일 반 돈다. 과제 제출 시점에는 중간 숫자만 있고, 병원 연결은 수십 건 이하라 초기 신호로만 본다.
- 메타는 50~60대 도달이 약해 40대 위주로 치우친다.
- 배포가 늦어 광고를 못 돌리면 이 문서를 출시 후 첫 검증 계획으로 둔다.

## 단계별 최적화 계획

지금은 1단계다. 메타가 최적화할 전환 이벤트를 퍼널 아래로 한 칸씩 내린다. 처음부터 병원 연결로 최적화하면 전환이 너무 적어 메타가 학습하지 못한다.

| 단계 | 광고 목표 | 최적화 이벤트 (픽셀) | 넘어가는 시점 |
|---|---|---|---|
| **1. 트래픽 수집 (지금)** | 트래픽 | 랜딩 페이지 조회 | 이번 집행(10월 2~5일)으로 클릭당 비용과 체크 완료율을 확인한 뒤 |
| 2. 설문 제출 | 전환 | 체크 완료 (`Lead`) | 체크 완료가 광고 세트당 주 50건쯤 쌓여 학습이 안정되면 |
| 3. 병원 연결 | 전환 | 병원 정보 보기·전화 버튼 클릭 (`ClinicClick`) | 최종 목표. 병원 연결 1건당 비용을 병원 광고비와 비교한다 |

- 병원 정보 보기(외부 링크)와 전화 버튼은 같은 목적이라 픽셀에 `ClinicClick` 하나로 보낸다. 메타는 광고 세트 하나를 전환 이벤트 하나로 최적화하므로, 둘을 나누면 각각 데이터가 모자란다.
- 넘어가는 시점의 "주 50건"은 메타가 학습 단계를 마치는 데 권장하는 대략의 기준이다. 실제 집행 숫자를 보고 조정한다.

## 작성 제약

- **배우자 시점:** 당사자가 느끼는 증상이 아니라 배우자 눈에 보이고 들리는 장면으로 쓴다. 모든 소재가 "남편"으로 부른다.
- **메타 개인 특성 정책:** 보는 사람 **본인**의 건강·나이 같은 특성을 짚으면 반려된다("60년대생 여성"). 남편의 코골이나 각방 같은 제3자·생활 상황 표현은 괜찮다.
- **효과 보장 금지:** "사라집니다"가 아니라 "사라질 수 있어요".
- **수치는 출처 있는 것만:** [evidence](../research/evidence.md)의 [사실] 항목만 쓴다.
- **심혈관 위험은 치료와 엮지 않는다.** 무작위 시험(SAVE, NEJM 2016)에서 양압기로 심혈관 사건이 줄지 않았다. 근거 수치가 치료하지 않은 중증 기준이라 숫자 없이 가능성만 말한다.
- **후기는 실제 인용만:** 실제로 한 말이고 광고 사용 동의를 받은 경우에만 쓴다. 지어낸 후기는 표시광고법상 거짓 후기다. 의료법 56조는 의료기관·의료인을 알리는 광고에 적용되어 직접 대상은 아니지만, 병원 광고 수익으로 병원에 보내는 구조라 효과를 단정하지 않는 문장을 쓴다.

## 소재

공통 필드. 자리마다 역할을 나눠 같은 말을 반복하지 않는다.

| 필드 | 문구 | 역할 |
|---|---|---|
| 이미지 하단 띠 | 남편 대신 해보는 3분 코골이 무료진단 | 무엇인지. 인스타에서는 헤드라인·설명이 안 보여 3분·무료를 여기에 둔다 |
| 헤드라인 | 결과 리포트 바로 받기 | 무엇을 얻는지 |
| 설명 | 남편 자는 모습만 떠올리면 돼요 | 얼마나 쉬운지 |
| 버튼 | 더 알아보기 (메타 고정 목록) | 행동. 문구를 직접 쓸 수 없다 |

| 소재 | 각도 | 기본 문구 | 근거 | 시안 |
|---|---|---|---|---|
| A | 치료 가능 (질문) | 20년 참은 남편 코골이, 치료하면 없어진다고? | 작성자 어머니 인터뷰([voc](../research/voc.md)) | [A](creatives/A-v3.png) |
| B | 병 신호 | 코골다 "컥" 하는 남편, 이 병일 수 있어요. | 한국 OSA 환자 중 목격된 무호흡 남 73.9%(Pyun et al., Sleep Med Res 2020). 숫자는 문구에 쓰지 않는다 | [B](creatives/B-v3.png) |
| C | 수면 피해 | 남편 코골이, 평생 이렇게 살아야 할까요? | — | [C](creatives/C-v3.png) |
| D1 | 졸음 운전 위험 | 밤새 코 골더니, 운전하다 꾸벅? 수면무호흡이면 사고 위험 2.4배. | 교통사고 위험 약 2.4배(Tregear et al., JCSM 2009) | [D1](creatives/D1-v3.png) |
| D2 | 심혈관 위험 | 문 닫아도 들리는 남편 코골이, 방치하면 심근경색·뇌졸중까지 올 수 있어요. | 미치료 중증 OSA: 심근경색·뇌졸중 사망 OR 2.87(Marin et al., Lancet 2005, 남성 관찰 연구) | [D2](creatives/D2-v3.png) |

- 각도가 서로 다른 소재를 넣어, 메타가 반응 좋은 쪽을 찾게 한다.
- A의 "20년"은 실제와 맞는 것을 확인했다.
- A는 후기형에서 질문형으로 바꿨다. 따옴표와 익명 출처("68년생 여성 이모씨")가 건강기능식품의 지어낸 후기 광고처럼 보여 오히려 안 눌릴 수 있다.

## 이미지

피드에서는 이미지 안 글자가 가장 먼저 읽힌다. 기본 문구를 이미지 안에 그대로 넣는다.

| 영역 | 내용 |
|---|---|
| 1. 후킹 문구 | 기본 문구 앞부분. 가장 크게, 두 줄 |
| 2. 보조 문구 | 기본 문구 뒷부분. 작게, 1줄. A·C는 후킹 문구에 다 들어가서 없다 |
| 3. 장면 | 소재별 장면 (A "조용~" 말풍선과 신기해하는 아내, B "컥!" 말풍선과 놀라서 깬 아내, C 귀마개 낀 아내와 새벽 시계, D1 졸며 운전하는 남편, D2 닫힌 문 너머 코골이) |
| 4. 하단 띠 | "남편 대신 해보는 3분 코골이 무료진단". 노랑 띠, 좌우로 꽉 채움, 가운데 정렬, 화살표 없음 |

- 출처: 근거가 논문인 D1·D2는 보조 문구 아래에 작게 출처 한 줄을 넣는다.
- 1080×1080. 레이아웃, 폰트, 색은 모두 같게 두고 문구와 장면만 바꾼다.
- 큰 글씨는 후킹 문구 하나만 둔다. 장면은 화면의 절반 이하로 두고 아래쪽은 띠에 가려지게 한다.
- 서비스명은 넣지 않는다. 광고 위에 페이지 이름이 이미 보인다.
- 하단 띠를 넣는 이유: 인스타 피드는 헤드라인이 거의 안 보여서 3분·무료가 묻힌다. 띠는 행동("→")이 아니라 무엇인지를 말해 아래 메타 CTA 버튼과 역할이 겹치지 않게 한다. 인스타에서는 띠 바로 아래에 버튼 줄이 붙어 한 덩어리로 읽힌다.
- "남편 대신 해보는"은 본인이 아니라 배우자가 하는 것임을 알리고, "진단"이 의사의 진단으로 읽히지 않게 누른다. "자가진단"은 배우자가 하는 것이라 정확하지 않아 쓰지 않는다.
- "3분": 실제로는 30초~1분이면 끝나지만, "진단"의 무게를 살리고 더 걸릴 일이 없게 3분으로 둔다. 체크 화면 제목(3분 코골이 체크)과도 맞는다.
- 예비 띠 문구: "진단"으로 반려되면 "남편 대신 해보는 3분 코골이 테스트 · 무료"로 바꾼다.
- 예비 소재 A-alt 시안은 이전 배치다. 쓰게 되면 같은 배치로 다시 만든다.
- 얼굴이 정면으로 나오는 사진, 의료기기, 병원은 넣지 않는다.
- **일러스트를 쓰는 이유:** AI 생성 실사 사진은 가짜처럼 보여 신뢰를 깎고, 차분한 정보형 톤은 피드에서 묻힌다. 일러스트로 눈에 띄게 하고, 신뢰는 서비스명·출처로 보강한다. 광고를 누른 사람이 끊기지 않게 랜딩 첫 화면에 같은 일러스트와 남색·노랑 색을 이어 쓴다.

## 관련 결정

광고와 맞물린 결정 중 다른 문서에 있는 것이다.

| 결정 | 문서 |
|---|---|
| 광고를 가설 검증(어떤 메시지가 이기나)이 아니라 유입 검증(배우자를 데려올 수 있나)으로 둔다. 당사자 카피 vs 배우자 카피 비교는 뺐다 | [가설 검증](../validation.md#메타-광고-유입-검증) |
| 유입이 1순위 리스크다. 검색하지 않는 배우자를 광고로 데려올 수 있는지 보여주는 공개 자료가 없다 | [솔루션 방향](../solution-direction.md#솔루션-방향) |
| 소재는 여러 개지만 랜딩은 하나다. 소재는 `utm_content`로 구분한다. 화면 문구는 광고와 같은 "3분 무료진단"을 쓴다 | [화면 설계](../ux-spec.md) |
| 메타 픽셀에는 결과 단계와 체크 응답을 보내지 않는다. 리포트 주소(`#` 뒤)가 있는 화면에서는 픽셀을 부르지 않는다 | [아키텍처](../architecture.md) |
| 병원 연결 1건당 비용을 병원 광고비로 감당할 수 있는지가 사업성의 핵심 숫자다 | [비즈니스 임팩트](../business-impact.md) |
