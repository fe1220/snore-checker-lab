# 스펙: 판정 단계별 퍼널 측정

상태: 승인

> **목적:** 2차 메타 광고 전에 "체크 완료 → 병원 목록 진입 → 병원 연결"을 판정 단계별, 사람 수 기준으로 볼 수 있게 한다.
>
> **결론:** 체크 완료 때 판정 단계를 GA 사용자 속성으로 저장하고, `make meta-report`에 사람 수 기준 퍼널과 판정 단계별 표를 더한다. 클릭 이벤트는 새로 달지 않는다.

## 배경

- [H2](../../validation.md#h2-판단-기준을-몰라서-참는다)를 판정 단계별 병원 연결률로 확인하기로 했다. 북극성 지표도 검사 권유 단계로 좁혀 본다([솔루션 방향](../../solution-direction.md#성공-지표)).
- 지금 리포트는 GA4 이벤트 수를 센다. 한 사람이 병원 여러 곳을 누르면 병원 연결이 여러 번 잡힌다.
- 병원 목록 진입은 `/clinics` 페이지뷰로 GA에 잡히지만 리포트가 세지 않는다.
- 판정 단계(`level`)는 `check_complete` 이벤트에만 붙어, 병원 목록 진입과 병원 연결은 단계별로 나눌 수 없다.

## 요구사항

1. **사용자 속성:** `check_complete`를 보낼 때 판정 단계(`strong` / `moderate` / `weak`)를 GA 사용자 속성 `check_level`로 저장한다. 이후 페이지뷰, `clinic_click`, `clinic_call`에 같이 붙는다.
   - 메타 픽셀에는 보내지 않는다(지금과 같다).
   - 응답 내용은 보내지 않는다. 판정 단계는 이미 GA로 보내고 있는 값이다.
   - 같이 `report_source: "self"`를 저장한다.
1-1. **공유받은 리포트(S3'):** 공유 링크로 리포트를 연 사람도 판정을 본 사람이다. 배우자 경로에서는 실제로 병원에 가야 할 당사자이기도 하다. 리포트를 열 때 해시에서 계산한 판정 단계를 `check_level`로, `report_source: "shared"`를 저장한다. 해시(응답)는 보내지 않는다.
   - 응답자 역할(당사자/배우자)은 랜딩 첫 문항 작업에서 같은 방식으로 `respondent_role` 속성을 더한다. 이번 범위가 아니다.
2. **리포트: 사람 수 기준 퍼널.** 광고 유입(지금과 같은 조건: `sessionSource`, 국가) 사용자 수로 센다.
   - 체크 완료: `check_complete`를 보낸 사용자 수
   - 병원 목록 진입: `/clinics` 페이지뷰를 보낸 사용자 수
   - 병원 연결: `clinic_click` 또는 `clinic_call`을 보낸 사용자 수(한 사람은 한 번)
   - 합계와 소재별(`utm_content`)로 보여준다.
3. **리포트: 판정 단계별 표.** 위 세 숫자를 `check_level`과 `report_source`(직접 체크 / 공유받음)별로 나누고, 병원 목록 진입률과 병원 연결률을 계산한다. 공유받은 사람은 체크 완료가 없으므로 비율 대신 사람 수를 본다.
   - GA에 맞춤 측정기준이 등록되지 않았거나 데이터가 없으면 리포트 전체를 실패시키지 않고 "판정 단계별 숫자는 아직 없다"고 쓴다.
   - 속성이 없는 사용자(배포 전 체크, 다른 기기로 다시 들어온 사람)는 "단계 없음" 줄로 따로 둔다.
4. **기존 표는 그대로 둔다.** 이벤트 수 기준 표는 1차 결과와 이어 보도록 남기고, 이벤트 수라는 걸 표 위에 적는다.

## 수동 작업 (사용자)

- GA 관리자 → 맞춤 정의 → 맞춤 측정기준 만들기: 범위 "사용자", 사용자 속성 `check_level`과 `report_source` 두 개. 등록 전 데이터는 나중에 소급되지 않는다. 그래서 2차 광고 전에 등록한다.

## 범위 밖

- 랜딩 첫 문항, 경로(`respondent_role`) 속성. 랜딩 개선 작업에서 한다.
- 새 클릭 이벤트.
- 1차 리포트(`2026-10-05.md`) 다시 만들기.

## 성공 기준

- 체크를 끝내면 GA DebugView나 `dataLayer`에 `check_level` 사용자 속성이 보인다.
- `make meta-report`가 사람 수 기준 퍼널과 판정 단계별 표를 쓴다. 맞춤 측정기준이 없어도 리포트가 실패하지 않는다.
- `make gate` 통과.
