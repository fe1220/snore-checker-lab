## 출발점: 실제 사례

**아버지 → 수면무호흡, 양압기 치료**

1. 아버지는 머리만 대면 잠들었다. 본인은 익숙해서 문제로 여기지 않았다.
2. 나는 수면장애일 수 있다고 생각했다. 두 가지가 걱정됐다.
   - 수면장애가 있으면 심혈관 질환 위험이 올라간다고 해서, 나이 드신 아버지 건강에 나쁜 영향이 오래 쌓일까 봐.
   - 아버지가 운전하다 깜빡 조는 걸 가끔 봤다. 사고로 이어질까 봐.
3. 아버지에게 검사를 받아보라고 했지만 듣지 않았다.
4. 아버지보다 설득이 쉬운 엄마에게, 아버지를 데리고 검사받으러 가달라고 했다.
5. 네이버 지도 리뷰를 보고 병원을 찾아 추천까지 해줬다.
6. 검사 후 양압기 치료를 시작했다.

**전해 들은 사례: 어머니의 지인 → 남편 수면무호흡**

1. 어머니의 지인(여성)이 코 고는 남편을 병원에 데려갔다.
2. 아내의 동기는 남편 건강 걱정이 아니라 **코골이 소음이 너무 심해 같이 자기 힘들어서**였다.

**두 사례에서 얻은 것**

| 관찰 | 문서에 반영한 곳 |
|---|---|
| 본인은 증상에 익숙해 문제로 여기지 않았다. 의료계엔 이미 해결책(양압기)이 있었다 | [왜 문제인가](problem-definition.md#왜-문제인가), [막힘 ②](problem-definition.md#어디서-막히나) |
| 증상을 먼저 이상하다고 본 건 옆 사람이었다 | [사용자 = 배우자](problem-definition.md#누구를-위한-것인가) |
| 배우자의 동기는 **자기 수면 피해(코골이 소음)**였다 | [한 줄 요약](problem-definition.md#한-줄-요약). 결과 메시지는 수면 불편에 건강 위험을 더한다([H2](validation.md#h2-판단-기준을-몰라서-참는다)) |
| 작성자(자녀)는 아버지 건강이 걱정됐지만, 매일 밤 피해를 겪는 건 아니었다 | 서비스가 이 자녀 역할을 대신한다. 사용자는 배우자 |
| "검사받아봐"라는 말만으로는 움직이지 않았다 | [막힘 ②](problem-definition.md#어디서-막히나) |
| 본인보다 배우자를 설득하는 게 더 쉬웠다 | 사용자를 배우자로 정한 근거 |
| 병원은 **리뷰를 보고** 골랐다 | 병원 목록 화면. 크롤링 데이터에 리뷰가 없어 리뷰 표시는 [만들지 않는다](solution-direction.md#만들지-않을-것) |
| 병원 찾기와 추천까지 옆 사람이 했다 | [북극성 지표](solution-direction.md#성공-지표) = 배우자의 병원 링크 클릭 |

두 사례 모두 진료까지 간 건 본인 의지가 아니라 **옆 사람이 움직였기 때문**이다. 단 두 사례이므로 이는 가설의 출발점이지 근거가 아니다.

문제의식은 또 하나의 경험에서 시작됐다. 남자친구는 잠 많은 체질이라 여기다가 작성자의 권유와 예약으로 기면증 진단을 받았다. 처음엔 기면증도 범위에 넣었지만, 옆 사람이 매일 밤 피해를 겪는 구조가 아니고 비즈니스 규모가 작아 최종 범위에서 뺐다 (자료는 [archive](archive/other-sleep-disorders.md)).

| 질문 | 결론 |
|---|---|
| 문제 후보는? (비급여 비교, 건강검진, 증상→진료과, 실손 청구) | 증상→진료과에서 출발했지만, 작성자 경험을 계기로 "치료법은 있는데 병인 줄 몰라 방치되는 문제"로 옮겼다 |

| 누가 쓰나? | 매일 밤 코골이를 겪는 배우자·연인. 본인은 코를 곤다는 건 알지만 급할 이유가 없다 |
| 본인은 못 데려오나? | 처음엔 반전 카피("머리만 대면 5초 만에 잠드세요?")로 본인도 데려오려 했다. 사용자를 배우자로 정한 뒤, 당사자 카피는 메인 입구가 아니라 배우자 카피와 비교하는 데이터로만 쓰기로 했다(H1) |
| 수면장애는 몇 종류고, 무엇을 고르나? | ICSD-3 기준 7개 군. 처음엔 수면무호흡·기면증·렘수면행동장애 셋을 골랐다가 수면무호흡 하나로 좁혔다 |
| 기면증은 옆 사람 틀에 맞나? | 약하다. 낮 졸림은 옆 사람의 잠을 방해하지 않고, 후기에서도 본인·친구 말이 계기였다. 구조상 특발성 과다수면과 같은데 하나만 넣는 건 앞뒤가 안 맞았다 → 제외 |
| 왜 하나에 집중하나? | 비즈니스 임팩트, 배우자 동기, 크롤링 대상이 모두 수면무호흡에 모인다. 문항·카피·지표가 하나의 흐름이 된다 |
| 코골이와 수면무호흡은 같은가? | 다르다. 코골이는 질환이 아닌 증상·정상 변이이고 훨씬 흔하다. 습관성 코골이 남성의 약 5명 중 1명이 수면무호흡으로 추정된다 |
| 가족 건강 걱정과 본인(배우자) 불편 중 무엇이 동기인가? | 배우자는 자기 수면 피해가 더 클 수 있다(H6). 코골이 증상자의 절반이 각방을 쓴다. 이 동기를 쓰는 서비스·클리닉은 없다 |
| 비즈니스 임팩트가 있나? | 있다. 숨은 환자 유입이 수면 진료 시장의 병목이다 |
| 병원은 광고할 만큼 돈이 되나? 비급여보다 낮지 않나? | 비급여 진료과와 비교하면 낮다. 하지만 실제 고객인 이비인후과 의원(매출 88%가 급여, 내원당 약 3.2만 원) 기준으론 검사 1건이 내원 약 21일분인 고단가 항목이고, 수술·구강내장치 같은 비급여로도 이어진다 |
| 수면클리닉은 실제로 적은가? | 아니다. 95곳은 학회 인증 수다. 수면다원검사 실시기관은 742곳이고 대부분 동네 이비인후과다 |
| 진료 이후 병원 리텐션은? | 약하다. 양압기 장기 순응률은 약 3.8년 시점 12.2%이고, 병원은 양압기 관리 수가가 없어 수입이 첫해 검사에 몰린다. 그래서 병원은 신규 환자가 계속 필요하다 |
| 양압기 업체가 광고주일 수 있나? | 업체에게 환자 가치는 크지만, 이 서비스는 후원 없이도 진단 환자를 늘려 모든 업체가 이익을 나눠 갖는다. 중립성 때문에 줄 대가도 없어 후원 동기가 없다. 수익원에서 제외 |
| 기존 비급여 병원 연결과 무엇이 다른가? | 카테고리가 아니라 문제가 다르다. "어디로 갈까"가 아니라 "가야 하나"를 푼다 |
| 왜 수면다원검사로 연결하나? | 하지 않기로 했다. 첫 행동은 외래 진료이고 검사는 의사가 판단한다 → 목적지를 "수면 전문 진료"로 바꿨다 |
| 건강보험 적용을 알려줘야 하나? | 의원이 상담에서 알려준다. VOC에서도 비용은 장벽이 아니었다 |
| 레즈메드는 이 문제를 푸는 서비스가 맞나? | 맞다. [사실] 레즈메드코리아 홈페이지가 수면 자가테스트(41문항, "본인/친구·가족" 선택)와 수면다원검사 병원찾기(337곳, 병원별 상세 페이지)를 직접 운영하고, 코골이를 넘기지 말라는 인식 개선 캠페인("Don't Snooze the Snore", 2025)도 했다([competitors](research/competitors.md)). 자가테스트로 의심하게 하고 병원찾기로 검사에 잇는 흐름이 이 서비스와 같다. [추정] 양압기 회사라 진단받는 환자가 늘면 양압기 수요도 는다 |
| 같은 문제를 푸는 서비스가 있나? | 관찰자 문항과 중립 연결을 함께 갖춘 곳은 없다 |
| 수요를 창출하는 건가? | 새로 만드는 게 아니라 드러나지 않은 수요를 깨운다 |
| 지연형과 미치료형 중 어느 쪽인가? | 수면무호흡은 한 번도 진단받지 않은 사람이 다수(약 80% 이상)다. 둘 다 환자·병원 모두에 가치가 있다 |
| 진료받지 않는 85%가 모두 한 번도 안 간 사람인가? | 아니다. 연간 진료 인원 기준이라 진단 후 치료를 그만둔 사람도 섞여 있다. 진단 경험률(0.5%)로 보면 한 번도 진단받지 않은 사람은 환자의 약 80% 이상이다. 중단자는 범위 밖 |
| 사용자를 같은 방에서 자는 사람으로 한정하나? | 아니다. 각방을 써도 관계의 불편과 건강 걱정은 남는다. 같이 사는 배우자·연인으로 본다 |
| 앱에서 수면을 측정·진단하면? | 하지 않는다 (규제·정확도·이탈). 대신 분석 없는 관찰 기록 가이드를 넣는다 |
| "옆 사람"은 사실인가 가설인가? | 가설이다. 옆 사람이 증상을 겪는다는 건 근거가 있지만, 다음 행동이 막혀 멈춘다는 건 작성자 사례와 정성 근거뿐이다. [사실]/[추정]/[가설]을 표시하고 H1~H6에 검증 방법을 붙였다 |
| 본인과 옆 사람 중 누구를 설득해야 하나? | 미리 정하지 않는다. 두 경로를 모두 열고 세그먼트별 병원 연결률을 비교한다. 이후 사용자를 배우자로 정하면서 이 가설은 뺐다 |
| 대상을 수면무호흡에서 코골이로 넓히나? | 넓힌다. 배우자가 겪는 건 코골이고, 배우자는 진단이 아니라 소음이 끝나기를 원한다. 그냥 두면 안 되는 의학적 이유는 수면무호흡으로 유지한다. 어느 쪽이든 다음 행동은 이비인후과 상담과 수면검사로 같다 |
| 단순 코골이도 치료법이 있나? | 있지만 덜 확실하다. 구강장치는 표준 권고, 수술은 단기 효과·재발 흔함. 비급여다. 그래서 진료는 권하되 시술은 권하지 않는다 |
| 단순 코골이 수술은 과잉진료인가? | 그렇게 단정할 근거는 약하다. 정확히는 장기 효과 근거가 약하고 재발이 흔하며, 수면검사 없이 하면 수면무호흡을 놓칠 위험이 있다 |
| 배우자가 각방·귀마개로 이미 해결하고 있지 않나? | 단정하지 못한다. 잠자리를 분리한 뒤 해결 의지가 사라지는지 직접 잰 연구는 없다. 따로 자던 부부도 진료까지 왔고 치료 후 72.4%가 다시 같이 잤다는 사례가 있어 H5로 검증한다. 각방을 써도 수면무호흡은 남는다 |
| 코를 고는 본인은 모르나? | 코를 곤다는 건 안다. 모르는 건 얼마나 심한지, 숨이 멈추는지, 건강 문제일 수 있다는 것이다. 소음 피해는 배우자가 겪어 본인은 급할 이유가 없다 |
| 문제 정의를 어떻게 쓰나? | 한 문장으로 짜내지 않는다. 누가 겪나 / 무엇을 겪나 / 왜 해결되지 않나 / 왜 그냥 두면 안 되나로 풀어 쓴다. "다시 함께 자기"처럼 특정 결과를 필요로 단정하지 않는다 |
| 증상 신호(숨 멈춤·헐떡임·낮 졸림)를 알려주는 게 문제 해결인가? | 아니다. 증상 정보는 쉽게 찾을 수 있다. 처음엔 경로 정보와 공수가 비어 있다고 봤지만, 피드백 후 그것도 검색으로 풀린다고 보고 주원인에서 내렸다 |
| 코골이가 질환이고 치료 가능하다는 걸 대중이 아나? | 막연한 필요성은 안다(71%). 하지만 검사가 필요한 걸 모름 67%, 양압기 인지 26%. 다만 병원에 안 간 이유 1위는 "치명적이지 않다고 봄"이라, 모르는 것보다 심각하게 여기지 않는 게 더 크다 |
| 그럼 병목은 무엇인가? | 처음엔 "다음 행동을 모르고 공수가 크다"로 봤다. 피드백 후 "당사자는 괴롭지 않고, 괴로운 배우자는 판단 기준과 근거가 없다"로 바꿨다 |
| 옆 사람이 실행을 떠맡는 게 문제인가? | 아니다. 그건 움직일 동기가 있는 사람이 있다는 뜻이고, 이 서비스의 사용자가 누구인지에 대한 답이다 |
| 옆 사람이 "병원 가봐"라고 하면 가나? | 안 간다. 옆 사람이 병원을 찾아 추천하거나, 설득이 더 쉬운 배우자를 통해야 간다 → 전환의 주인공은 옆 사람이다 |
| 수면클리닉은 지금 어떻게 마케팅하나? | 전문성·편의 중심의 "병원 고르기" 마케팅이고 관찰자·배우자 유입 경로는 비어 있다. 니즈는 정황상 중상 |
| (피드백) 왜 모르는 상태로 그대로 있나? 안 괴로운 거 아닌가? | 당사자는 실제로 안 괴롭다. 밤 증상을 본 적이 없고 소음 피해도 없다. 진료받지 않은 이유 1위도 "치명적이지 않다고 봄"(54.4%)이다. 괴로운 건 배우자라, 괴로운 사람과 병원에 가야 하는 사람이 다르다는 게 문제의 핵심이 됐다 |
| (피드백) "몰라서"가 원인인가? 진짜 괴로우면 방법을 찾지 않나? | "치료 가능한 줄 몰라서", "어디로 가야 할지 몰라서"는 원인에서 내렸다. 검색하면 찾을 수 있다. 남는 원인은 당사자가 심각하다고 여기지 않는 것, 배우자에게 판단 기준과 근거가 없는 것이다 |
| (피드백) 수면무호흡 환자 중 배우자가 있는 사람은 몇 %인가? | [추정] 약 65%. 심평원 2025 성별·연령별 진료 환자 수에 통계청 2020 인구총조사 유배우율을 곱했다. 미진단자가 진료 환자와 같은 구성이라는 가정이 붙는다. 양압기 환자 코호트에서는 77%. 배우자 있는 환자의 74%가 40~60대 |
| (피드백) 양압기가 진짜 해결책인가? | 쓰는 동안 효과는 확실하지만 장기 순응률은 12.2%이고, 심혈관 사건 감소는 무작위 시험에서 확인되지 않았다. "확실한 치료"라는 표현을 내리고, 진단의 가치를 "맞는 치료를 고르는 것"으로 고쳤다. 양압기를 아는 사람이 26%라 양압기가 싫어서 진단을 피한다고 보지는 않는다 |
| (피드백) 병원은 왜 적극적으로 홍보하지 않나? | 홍보는 하지만 이미 의심하는 사람에게 "우리 병원"을 고르게 하는 수준이다. 수가가 고정되고 검사마다 야간 인력이 들어 마진이 얇을 수 있다 [가설]. 그래서 수익 모델은 빈 검사 병상 채우기를 전제로 두고, 병원 인터뷰로 확인할 첫 질문으로 남겼다 |
| "권했는데 당사자가 안 갔다"를 문제로 잡나? | 아니다. 근거가 없고 대상이 좁아진다. 근거가 받치는 건 "당사자는 스스로 안 가고, 간 사람의 다수는 배우자가 계기였다"이다. 권유를 시작하지 못한 배우자와 권유가 약하게 끝난 배우자를 함께 본다 |
| 배우자를 겨냥한 메시지는 정말 없나? | 있다. 미국수면학회 "Stop the Snore", 영국 snorer.com, 캐나다 VitalAire 등이 배우자에게 말을 건다. 하지만 "신호를 알아채라"나 자사 상담·제품에서 끝나고 문항은 본인 기준이다. 그래서 차별점은 "배우자를 겨냥한다"가 아니라 "배우자가 본 것으로 체크하고 중립 병원 목록까지 잇는다"이다. 직접 확인한 46건 중 이런 곳은 0건이었다([benchmark](research/benchmark.md#주장과-어긋나는-사례)) |
| 그 외 동거인(룸메이트·형제)도 대상인가? | 아니다. 방을 옮기면 끝나는 관계라 당사자를 병원까지 이끌 이유가 약하다. 제품에서 막지는 않고 비교 데이터로만 본다 |
| "병원에 가지 않아 방치된다"가 문제 정의인가? | 아니다. 그건 현상이다("아파요"). 문제 정의는 진단처럼 누구의 어느 지점을 풀지 정해야 하고, 읽으면 무엇을 만들지와 무엇을 확인할지가 떠올라야 한다. 그래서 "배우자는 치료할 수 있는 건강 문제인지도 무엇부터 해야 하는지도 몰라서 당사자를 병원으로 이끌지 못한다"로 정했다 |

## 2026-10-02 방향 재정리

조사를 계속 넓히다 문제 정의가 흐려져서, 별도 세션에서 쓴 문제정의서(PDF, "수면무호흡 검사 연결 서비스 문제정의서")를 기준으로 다시 좁혔다. 이 섹션은 그날 나눈 질문과 결론을 정리 전 상태로 남긴다.

### 결정

- **메인 문제:** 병으로 직접 고통받는 사람(배우자)과 검사·치료의 주체(당사자)가 다르다.
- **쉬운 한 줄:** 남편이 코를 곤다. 괴로운 건 아내인데, 병원에 가야 하는 건 남편이다. 남편은 안 간다. 서비스는 아내가 남편을 병원에 보내게 돕는다.
- **막힘은 한 흐름 안의 두 지점이다.** ① 배우자도 병인지 모른다(기존 문서의 초점) → ② 당사자가 거부한다(PDF의 초점). 둘 중 하나를 고르지 않고 서비스 흐름 하나로 같이 푼다.
- **"설득"이 아니라 "거부 이유 없애기"로 본다.** 거부 이유 3개와 대응: "난 괜찮아"(본 적 없음) → 배우자 관찰을 증거로 / "너 때문이잖아"(희생 프레임) → 본인 이득으로 / "귀찮아"(첫 행동이 큼) → "가볼게" 버튼 하나, 병원 찾기는 배우자.
- **치료 이후 문제는 범위 밖, 후속 과제로 뺀다.**

### 검토한 질문

| 이비인후과도 마케팅을 많이 하나? | 외래형(감기·비염, 급여 박리다매)은 위치 접근성 중심이라 적다. 수술 전문형(코골이·비중격·축농증)은 검색광고·블로그·카페에 쓴다. 의료광고 사전심의가 있어 정보성 블로그·우회 바이럴이 많다 [업계 일반 지식, 미확인] |

### 인터뷰 보강 (작성자 부모)

상세는 [VOC 인터뷰](research/voc.md#인터뷰-아버지-수면무호흡)로 옮겼다. 요지만 남긴다.

- 작성자가 지금 만들려는 서비스의 역할을 직접 해서 성공한 사례다. 문제 정의의 출발점이자 서비스 설계 원본(카피 구조: 계속 이렇게 자면 → 당신 건강에 → 수면다원검사 한번)으로 쓴다.
- 실제 경로는 자녀 → 엄마 → 아빠였다. 작성자가 엄마를 움직였고, 아빠는 엄마가 가자고 하면 따라갔다. 당사자를 설득한 게 아니라, 배우자에게 근거를 줘서 배우자가 움직이게 했다. 서비스는 이 제3자(자녀) 역할을 대신한다.
- **함의:** 이 집에서 막힌 곳은 ②(당사자 거부)가 아니라 ①(배우자가 병인지 모름)이었다. PDF의 "당사자 거부" 초점보다 기존 문서의 "배우자에게 기준과 근거가 없다" 초점에 가까운 근거다. 어느 쪽을 메인으로 둘지 다시 정해야 한다.
- **결정:** 작성자가 엄마에게 준 건 네 가지(병일 수 있음, 치료 가능, 방치 시 건강 위험, 병원·예약·검사 경로)였고, 이게 서비스 화면과 1:1로 맞는다. 그래서 ①(배우자에게 판단 기준과 경로가 없다)을 메인으로, ②(당사자 거부)는 당사자 리포트로 대응하는 보조 단계로 둔다. 예전 문서에서 "검색하면 나온다"며 보조로 내렸던 경로 정보는 "판단을 행동으로 바꾸는 마지막 단계"로 다시 올린다. 북극성 지표는 배우자의 병원 외부 링크 클릭률로 바꾼다.
- 치료 이후 문제(착용 불편, 비수면 내시경, 보험 기준, 유지 동기는 "아내를 위해")는 후속 과제로 뺐다. 양압기 사용자가 늘면 장비·관리 서비스·커뮤니티도 좋아질 수 있다는 가설도 함께 남긴다.

| 당사자 카피와 배우자 카피를 비교한다(이전 H1) | 사용자는 40~60대 배우자 하나. 카피 비교는 하지 않고, 출시 후 H1(배우자에게 말을 거는 게 낫다)의 확인 방법으로만 남긴다 |
| 경로 정보는 검색하면 나와서 주원인에서 내린다 | 경로는 "판단을 행동으로 바꾸는 마지막 단계"로 다시 올렸다(병원 목록) |
| 건강보험 적용은 병원이 알려준다 | 결과 화면에 검사 과정과 비용(약 12~14만 원)을 보여준다 |
| 앱에 분석 없는 관찰 기록 가이드를 넣는다 | 넣지 않았다. 체크 문항이 관찰 항목을 대신한다 |
| 목적지는 수면 전문 진료, 수면다원검사로 직접 연결하지 않는다 | 유지. 목록의 병원은 수면다원검사 실시기관이고, 첫 행동은 외래 진료로 안내한다 |

## 2026-10-03 가설 재정리

문제 정의를 다시 읽다가 "문제 정의에 가설이 섞여 있다"는 데서 시작해, 문서 구조와 가설 구조를 문제 정의의 논리에 맞춰 다시 짰다. 결과는 [validation](validation.md#한눈에-보기)에 있다.

### 결정

- **문제와 해법을 나눈다.** [problem-definition](problem-definition.md)에는 문제(사실과 근거)만 남기고, 핵심 가설·만들지 않을 것·성공 지표·리스크는 [solution-direction](solution-direction.md)으로 옮겼다.
- **가설은 퍼널 단계가 아니라 문제 정의의 논리 순서로 세운다.** 왜 배우자인가 → 판단이 왜 안 서나 → 판단이 서면 행동으로 넘어가나 → 당사자는 따라가나.

| # | 가설 | 문제 정의에서 맡는 곳 | 확인 |
|---|---|---|---|
| H1 | 당사자보다 배우자가 움직일 동기가 크다. 그래서 배우자에게 말을 거는 게 병원까지 더 잘 이어진다 | 전제 | 문헌·설문. 비교 실험은 출시 후 |
| H2 | 배우자는 판단 기준(병인지, 치료되는지, 위험한지)을 몰라서 참는다 | ① 원인 | 결과 → 병원 목록 진입률 |
| H3 | 판단이 서도 경로가 없으면 행동으로 넘어가지 않는다 | ① 전환 | 병원 목록 → 병원 연결(링크·전화) |
| H4 | 배우자가 가자고 하면 당사자는 대부분 따라간다 | ② 보조 | 공유율 |

- **근거를 커뮤니티 밖으로 넓힌다.** 논문 14편을 [literature](research/literature.md)로 정리했다. 82cook 수집이 17건에서 막혀 커뮤니티 근거만으로는 모든 가설이 판정 보류였다.
- **북극성 지표를 "병원 연결"로 바꾼다.** 외부 링크 클릭과 전화 걸기는 같은 목적이라 합친다. 메타 픽셀에도 둘 다 `ClinicClick`으로 보낸다.

### 검토한 질문

| 질문 | 결론 |
|---|---|
| 문제 정의가 가설을 포함해도 되나? | 실무에서 흔하지만, 이 문서는 사실상 PRD였다. 문제(사실)와 가설·솔루션을 나눠야 사고 과정이 보인다. "배우자에게 판단 기준이 없는 게 메인 병목"이라는 주장도 인터뷰 1건과 업계 설문에 기댄 것이라 [가설]로 표시했다 |
| 가설 근거가 커뮤니티에 너무 기대지 않나? | 맞다. 커뮤니티는 인식·반응을 보는 데는 괜찮지만, "알려주면 움직인다" 같은 인과는 볼 수 없다. 문헌을 찾았고, 배우자가 진료의 계기라는 건 질적연구 3건에서 일관됐다. 반대로 정보만 준 교육 RCT는 검사 이행률이 45.9% 대 45.6%로 차이가 없었다. 그래서 판단 기준과 경로를 따로 본다 |
| 메타 광고로 가설을 검증할 수 있나? | 어렵다. 클릭은 "궁금하다"이지 "몰랐다"나 "움직였다"가 아니고, 메타가 예산을 몰아줘 공정한 비교가 아니다. 광고는 **유입 검증이 1순위**이고, 소재 각도(병 신호, 치료 가능, 방치 시 위험, 수면 불편)는 정보별 반응의 참고 신호로만 본다 |
| 처음 구조(모른다 → 알면 간다 → 당사자 → 건강 위험)는 왜 바꿨나? | 퍼널 순서로 쪼개서 문제 정의의 출발점(왜 배우자인가)이 빠졌고, "알면 간다"는 핵심 가설을 그대로 다시 쓴 것이라 범위가 넓었다. "건강 위험이 가장 움직인다"는 문제 정의의 메인 주장이 아니라 결과 화면 설계용 질문이라 H2의 하위 질문으로 내렸다 |
| "몰라서 참는다"와 "알면 간다"는 같은 말 아닌가? | 논리로는 다르지만(모르는 것 말고 다른 장벽이 없어야 같다), 문제 정의가 "모르는 게 메인 병목"이라고 주장하므로 이 문서 안에서는 같다. 하나로 합쳤다 |
| 네 가지(병, 치료, 위험, 경로)를 한 가설로 묶어도 되나? | 아니다. 문제 정의 ①은 "판단 기준과 경로"이고, 둘은 역할이 다르다. 판단 기준은 갈 생각을 못 하게 막는 원인이고, 경로는 판단을 행동으로 바꾸는 전환이다. 나누면 퍼널의 다른 구간(결과 화면, 병원 목록)에서 따로 측정돼, 끊긴 곳을 보면 어느 가설이 틀렸는지 알 수 있다 |
| H1은 "배우자의 고통이 크다"인가 "배우자가 설득하기 쉽다"인가? | 둘 다 아니다. 고통이 크다는 건 거의 사실이라 검증할 게 없고, 배우자는 설득 대상이 아니라 판단 기준이 없는 사람이다. "동기는 배우자에게 있다 → 그래서 배우자에게 말을 거는 게 낫다"로 쓰고, 뒷부분을 검증한다 |
| 병원에 실제로 갔는지는 어떻게 아나? | 알 수 없다. 병원 외부 링크 클릭과 전화 걸기를 대리 지표로 쓰고, 전화가 예약에 더 가깝다. 방문 여부는 출시 후 병원 제휴 데이터로 확인한다 |
| 핵심 CTA가 둘(링크, 전화)이면? | 같은 목적의 두 수단이라 "병원 연결" 하나로 합치고 내역을 따로 본다. 메타는 광고 세트 하나를 전환 이벤트 하나로 최적화하므로 픽셀 이벤트도 하나로 보낸다. 이름은 기존 기록·맞춤 전환이 이어지도록 `ClinicClick` 그대로 둔다 |

### 함께 바꾼 것

- **결과 공유 문구:** 문헌에서 아내의 압박은 양압기 사용을 오히려 줄이고 함께하는 방식만 효과가 있었다. 당사자 화면 첫 줄의 "당신의…"를 "요즘 낮에 졸리고 피곤했다면, 수면무호흡증 때문일 수 있어요"로 바꿨다.
- **메타 광고 단계:** 트래픽 수집(지금) → 설문 제출(`Lead`) → 병원 연결(`ClinicClick`) 순서로 최적화 이벤트를 내린다([meta-ads](meta-ads/strategy.md#단계별-최적화-계획)).

## 2026-10-06 H1 재검토 (메타 1차 결과)

메타 광고 1차(10월 2~5일)와 일반 키워드 커뮤니티 글(3차)을 보고 H1을 다시 잡았다.

### 결정

- **문제 정의:** "판단 기준과 경로가 없어서 병원에 안 간다"만 문제로 둔다. "괴로운 건 배우자, 가야 하는 건 당사자"는 문제 정의에서 뺀다. 당사자도 피로와 눈치 같은 고충이 있고 스스로 찾아본다.
- **H1:** "배우자가 동기가 크다"(전제)에서 "당사자에게 말을 거는 게 병원까지 더 잘 이어진다"(검증할 가설)로 뒤집는다.
- **검증 방식:** 랜딩 첫 문항("내 코골이 / 가족 코골이")으로 경로를 나누고, 결과 조회 100건 이상에서 한쪽이 70% 이상이면 메인 타겟으로 잡는다. 못 넘으면 경로별 병원 연결률로 정한다.
- **랜딩:** 첫 문항 응답률 목표 27% → 50% 이상.
- **메타 2차:** 최적화 목표를 체크 완료(`Lead`)로 내린다. lab 저장소를 별도 링크로 배포해 새 캠페인을 보낸다.
- **GA 규칙:** 체크 완료 이벤트에 응답자 역할(당사자/가족)을 붙인다. 증상 응답은 지금처럼 보내지 않는다.

### 검토한 질문

| 질문 | 답 |
|---|---|
| 메타 예산이 남성에게 몰렸으니 당사자가 더 반응한 것 아닌가? | 성별만으로는 당사자인지 배우자인지 알 수 없다. 소재별 예산(A·D2에 몰림)도 근거로 쓰지 않는다. 소재마다 카피와 이미지가 모두 달라 어느 소재가 당사자도 받아들일 만한지 사후에 가를 수 없다. 메타는 랜딩 조회로 최적화해 클릭 단계 신호이고, 병원 연결은 5건이다. 그래서 경로를 직접 묻는 방식으로 바꿨다 |
| 메타가 예산을 몰아준 소재는 우연인가? | 메타는 클릭 수보다 많은 신호로 예상 반응률을 계산하므로, 예산 배분을 성과 신호로 본다. 다만 랜딩 조회 기준이다([분석](meta-ads/results/2026-10-05-analysis.md#4-소재-메타가-ad2에-예산을-몰았다)) |
| 커뮤니티 글은 왜 배우자 글이 많았나? | 1·2차 검색어가 모두 배우자 시점이었다. 일반 키워드 4,207건으로 다시 모으니 당사자 글 72%, 배우자 9%였다. 블라인드는 배우자 고민이 대부분으로 보여, 하소연은 배우자가, 해결책 검색은 당사자가 하는 채널 차이로 읽는다 |
| 체크 완료로 최적화하면 경로 비중이 메타 쪽으로 치우치지 않나? | 메타가 체크를 끝낼 사람에게 몰아주므로 비중이 "누가 끝까지 가나"를 보여준다. H1이 묻는 것과 같아 오히려 맞는 방향이다 |
| 원본 링크에 새 버전을 올리지 않는 이유는? | 원본 링크는 제출한 버전이다. 별도 링크면 옛 화면과 새 화면 유입이 호스트로 깔끔하게 나뉜다 |

## 2026-10-06 문제 정의 재편

H1을 뒤집은 뒤 문제 정의 문장을 다시 잡았다. 『기획은 2형식이다』의 방식(현상과 근본 원인을 나누고, 근본 원인을 문제로 정의)을 [문제 정의 전략](problem-framing.md)으로 정리하고 그 기준으로 문서를 다시 짰다.

### 결정

- **현상:** 수면무호흡 환자의 약 85%가 진료를 받지 않는다.
- **문제(근본 원인, 메인):** 단순 코골이와 수면무호흡을 가를 기준이 없다. 서비스의 역할은 판단을 내려줘 병원에 가겠다고 결심하게 만드는 것이다.
- **보조:** 판단이 서도 병원까지 가는 경로가 바로 이어지지 않는다. 결심한 사람을 병원에 연결하는 일이라 병원(고객) 쪽 가치다.
- **뺀 것:** 배우자 전제, 당사자 거부(배우자 경로의 리스크로 H4에), 대처에 쓰는 돈(비즈니스 임팩트로).
- **대상:** 당사자 경로와 배우자 경로를 상황으로 쓰고, 연령 근거를 배우자 기준(유배우율·부부 나이 차)에서 환자 기준(심평원)으로 바꿨다.
- **비즈니스 임팩트:** 숨은 환자는 병원이 아니라 코골이 용품 시장에 있다. 판정받은 사람을 병원으로 넘긴다. 시장 크기를 40~60대 남성 환자 기준으로 다시 계산했다(약 56만 명, 1%면 검사 매출 약 37억 원).

### 검토한 질문

| 질문 | 답 |
|---|---|
| 근본 원인을 여러 개 짚은 것 아닌가? | 처음 문장은 "고통받는 사람과 치료할 사람이 다르다"와 "배우자에게 판단 기준·근거·경로가 없다"가 섞여 있었다. 앞의 것은 바꿀 수 없는 조건이라 뺐고, 판단 기준을 메인, 경로를 보조로 나눴다 |
| 정보가 없어서 안 가는 건가? | 아니다. 커뮤니티 답변(지식인 중심)의 64%가 수면무호흡·검사를 언급한다. 비어 있는 건 내 경우를 가르는 기준이다 |
| "구분 기준이 없다"는 사람이 돈을 쓸 문제인가? | 사용자는 구분 기준에 돈을 쓰지 않는다. 돈을 내는 건 병원이다. 사용자 쪽은 이미 대처에 돈과 시간을 쓰고 있다는 게 근거이고, 이건 비즈니스 임팩트에서 다룬다 |
| 경로는 왜 보조인가? | 판단이 서면 검색으로 찾을 방법이 있다. 다만 어느 의료진에게 갈지 모른다는 응답(58%, 미국)도 있어 지우지 않고 H3으로 확인한다 |
| 5Why가 결론을 먼저 정하고 짜맞춘 것 아닌가? | 한 줄 사슬로 쓰면 그렇게 읽힌다. "왜?"는 여러 갈래로 나오므로 갈래를 나무로 펼친 뒤 크기(근거), 상위성, 통제 가능성으로 골랐다. "내가 해당되는지 모른다"가 판단 갈래 전체의 뿌리라 문제로, 실행 갈래(비용·검사 방식·병원)는 보조로, 근거 없는 "최후의 수단" 태도는 리스크로 뒀다. 근거가 없던 "자는 동안이라 확인할 수 없다"는 녹음 앱·워치가 있어 뺐다 |
| 녹음 앱·워치가 이미 판단해 주지 않나? | 워치는 수면무호흡 징후를 알려주지만 본인이 특정 기기를 여러 밤 차야 하고, "의사와 상담하세요"에서 끝난다. 녹음 앱은 코골이 점수만 준다. 기기 없이 시작하는 판정과 중립 병원 연결은 비어 있다 |
